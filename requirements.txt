# Platform-specific notes:
# =======================
# Windows: Some packages may require Visual C++ build tools
# macOS: Xcode command line tools may be required
# Linux: Development headers may be needed (python3-dev, libxml2-dev)

# Minimal installation:
# ====================
# For minimal functionality, only these are strictly required:
# requests>=2.28.0
# python-dateutil>=2.8.0
# lxml>=4.9.0 (for research domain)
# 
# Most APIs will work with just the requests library,
# but additional features require more dependencies.

# Memory and performance considerations:
# =====================================
# - pandas: Large memory footprint, consider alternatives for small datasets
# - numpy: Essential for numerical operations but adds size
# - lxml: Faster XML parsing than built-in xml module
# - aiohttp: Better for high-concurrency scenarios
# - diskcache: Persistent caching with minimal setup

# Security considerations:
# =======================
# - cryptography: Keep updated for security patches
# - requests: Verify SSL certificates by default
# - urllib3: Disable insecure request warnings in production
# - python-dotenv: For secure API key management

# Optional pip install commands for specific domains:
# ==================================================
# Environmental: pip install meteocalc pyowm
# Economic: pip install yfinance ccxt alpha-vantage
# Security: pip install shodan virustotal-api python-whois
# Media: pip install newspaper3k praw tweepy
# Research: pip install scholarly crossref-commons arxiv

# Docker considerations:
# =====================
# For containerized deployments, consider using:
# - python:3.9-slim base image
# - Multi-stage builds to reduce final image size
# - .dockerignore to exclude development dependencies
# - Health checks using the domain processors' statistics endpoints

# Installation troubleshooting:
# =============================
# If installation fails:
# 1. Update pip: python -m pip install --upgrade pip
# 2. Install build tools: pip install wheel setuptools
# 3. Use binary wheels: pip install --only-binary=all package_name
# 4. For ARM64/M1 Macs: Use conda for problematic packages
# 5. For Alpine Linux: Install build dependencies and use --no-cache
